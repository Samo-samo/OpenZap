# OpenZap

An open-source, cross-platform Smart TV controller built with Flutter.

OpenZap aims to provide a modern, lightweight and ad-free alternative to existing Smart TV remote applications by communicating directly with compatible TVs over the local network.

> OpenZap is an independent open-source project and is not affiliated with or endorsed by any TV manufacturer.

---

## Features

* Local network device discovery
* Smart TV remote control
* Wake-on-LAN
* Quick application launcher *(supported devices only)*
* Sleep timer
* Multi-language support
* Light and dark themes
* Modular architecture for future TV integrations
